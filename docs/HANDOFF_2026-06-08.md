## Architecture
- **`perception/lane.py`** — single-black-line follower (bird's-eye: warp →
  black mask → sliding window → poly fit `x=f(y)`). Robustness: `continuity`
  (anchor base to previous frame), `base_hist_h_pct`, `reject_transverse_rows`
  (anti-zebra: deletes dense transverse dash rows so it doesn't latch the cross),
  sticky base + branch guard near a cross (`lane_base_max_jump_pct`,
  `lane_base_hold_s`). Live params `lane.*`.
- **`perception/zebra.py`** — cross detector in a dedicated WIDE bird's-eye
  (`widen_kx`) in **ground cm**. RANSAC transverse dash row → `distance_cm`,
  `angle_deg`, `row_center_cm`, `options`. Side exits by dashes (relative to the
  cross centre); **STRAIGHT by continuous line** (`_detect_straight_line`).
  `option_align_deg` gate. Live params `zebra.*`.
- **`perception/signs.py`** — YOLO `config/best.pt`. **Spanish class names**:
  `give-way, stop, straight, trabajadores, vuelta-derecha, vuelta-izquierda`
  (mapped by substring aliases → `turn_left/right/go_straight/stop/workers/
  give_way`). Inference every `every_n` frames, upper band, small `imgsz`.
  Degrades to no-op if the model can't load (never breaks line following).
- **`line_follower.py`** (node `autonomous_racer`) — state machine:
  `FOLLOW → DETECT (zebra seen & dist≤detect_distance_cm) → ADVANCE (odometry
  from the COMMAND with REAL dt; stops at the first row by VISION: z_dist jump or
  dist≤read_distance_cm; goes straight, advance_center_gain=0) → READ (wait:
  optional square-up if skewed unless came_straight; vote options; wait for the
  MANUAL decision 1/2/3, OR auto-decide from a latched sign arrow) → COMMIT
  (cross by time, ends on lane re-acquire) → FOLLOW`. Telemetry UDP 5055 →
  `tools/dashboard.py`. H264 stream = live composite (camera+HUD | lane BEV |
  zebra BEV). `events.jsonl` + `controller_data.csv` per session.

## Traffic signs (YOLO) — gated by `use_signs`
- `workers` → slow to `workers_speed_factor` for `workers_slow_s`.
- `stop` → hold `stop_seconds`; `give_way` → `giveway_seconds`. Both only act when
  the sign is CLOSE (`area_pct ≥ sign_act_area_pct`).
- arrows / straight → latch `pending_turn`, auto-decide the next cross (manual
  `1/2/3` still works). Per-sign `sign_cooldown_s`.
- Launch with YOLO: `USE_SIGNS=1` makes the run script preload torch's libgomp
  (fixes the Jetson "static TLS block" error) and keep user-site (ultralytics is
  in `~/.local`). `ultralytics 8.4.56` is installed.

## Traffic light (HSV by shape)
- Detects the colored disc (calibrated HSV: red `H[0-10]∪[168-180] S≥90`, yellow
  `H[15-39]` (disc measured ~`(35,92,200)`), green `H[42-85]`). Shape filter
  (circularity / aspect / fill / area + upper ROI). Blanks a YOLO sign's box from
  the masks (so a STOP's red isn't read as a red light). Requires the disc to sit
  on the GRAY plate/screen (ring around the disc must be gray: `plate_max_sat=70`,
  `plate_min_val=45`, `plate_max_val=210`).
- **Optional light** (`traffic_light_optional=True`): drives by default, only
  obeys RED/YELLOW when actually seen; returns to GREEN when no light is in view.
  Does not wait for green to start.

## What works
FOLLOW straight/curve; cross detect → ADVANCE stops on the first row → READ asks →
COMMIT crosses. Manual `1/2/3` always obeyed. YOLO signs load & map (6 ES classes).
Traffic light detects the 3 colors by shape+plate. Session pull is fixed.

## Gotchas (do not repeat)
- **No fixed dt in loops** — the rate varies (~10-12 Hz with the composite stream);
  use real measured time. (A fixed dt made ADVANCE never reach READ.)
- **Odometry from the COMMAND**, not `/robot_vel` (reads ~0). The command
  overestimates real distance (motor deadband ~0.08-0.10 m/s; `approach_speed`
  0.06 → real ~0.046). ADVANCE therefore ends by VISION, not odom.
- **YOLO on Jetson**: needs LD_PRELOAD of torch's libgomp + no `PYTHONNOUSERSITE`
  (handled by `USE_SIGNS=1`).
- `best.pt` classes are **Spanish** (tolerant substring mapping).
- Track lines are always **black continuous**; dashes only mark crosses. STRAIGHT
  is a continuous line (not dashes). Measures: line 2.2 cm, lane 11.8 cm, dash
  2.2×3.15 cm, cross 26 cm deep. px/cm lane warp Y≈5.68 X≈7.94; zebra BEV X≈11.1
  Y≈23.6.
- Cross decision is always the operator's (`1/2/3`) or a sign; never guess by
  dashes.
- One follower at a time (`stop_demo` before relaunch). CSI camera via argus; if
  "No cameras available": `sudo systemctl restart nvargus-daemon`.
- Validate OFFLINE on the Jetson (push frames to `~/zebra_eval`, run an eval, pull
  composites) before pista. Don't break FOLLOW or the cross machine.
